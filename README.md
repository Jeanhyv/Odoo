# Presentación Amazon + Odoo ERP

Página web tipo presentación basada en la práctica 1.3.

## Archivos

- `index.html`
- `styles.css`
- `script.js`
- carpeta `assets/`

## Cómo subirlo a GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube todos los archivos y la carpeta `assets`.
3. Entra a `Settings > Pages`.
4. En `Branch`, selecciona `main` y `/root`.
5. Guarda y abre el enlace de GitHub Pages.
